# K 线策略信号(观星指点)设计

日期:2026-10-04
状态:已确认(用户选定「均线+RSI+布林 组合」方案)

## 目标

在 K 线图上直接给出「做 T 参考」:总结近期价格浮动(均线、RSI、布林带),
生成一个可读的结论(接回 / T出 / 观望),并把指标画在 K 线图上。
**仅做观察参考,不产生下单建议,不接告警/Telegram。**

## 拆分

两个叠层 PR:

1. **PR1 后端**:信号引擎 + API + 单测 + 本设计文档
2. **PR2 前端**:K 线区块下移加大 + 标注渲染 + 指标徽标栏(基于 PR1 分支)

## 后端

新增 `astrolabe/signals.py`,纯计算模块,无 IO:

- 输入 OKX 格式 K 线(newest-first,`[ts, o, h, l, c, ...]`)。
- 指标:
  - MA5 / MA20(简单均线),并检测最近一次金叉/死叉(近 30 根内)。
  - RSI(14),Wilder 平滑。
  - 布林带(20, ±2σ):upper / mid / lower 与 %B。
- 结论合成:
  - %B ≤ 0.2 且 RSI ≤ 30 → `buy_in`(「低位区间 · 可考虑接回做T」)
  - %B ≥ 0.8 且 RSI ≥ 70 → `sell_out`(「高位区间 · 可考虑T出」)
  - 其余 → `hold`(「观望」)
- 输出:指标当前值 + 结论(action/label/reason)+ **指标序列数组**
  (MA5/MA20/布林上中下轨,与时间轴对齐,供前端画线)。

新增 `GET /api/signals?instId=&bar=`:

- 后端自己经 OKX REST 拉 K 线(limit=100)并计算。
- 内存缓存 30 秒(per `instId+bar`),避免频繁切换周期打爆 OKX。
- 计算异常返回 `{"error": ...}`(502)。

## 前端

- 布局:K 线「观星图」区块移到页面最下方(行情簿、司天监、告警之下),
  高度加大到约 520px。
- 标注:布林上/中/下轨三条虚线叠在 K 线上;金叉/死叉在对应 K 线打箭头
  markPoint;最新一根 K 线按结论打「接回 🟢 / T出 🔴 / 观望 ⚪」标签点。
- 徽标栏:图表上方一栏小徽标显示 MA5 / MA20 / RSI / %B 当前值与结论文字,
  角落固定注明「信号仅供做 T 参考,非投资建议」。
- 切换品种/周期时与 K 线一起刷新 `/api/signals`。

## 测试

`tests/test_signals.py`:合成 K 线序列(持续上涨→RSI 满值 + %B 高位 →
`sell_out`;持续下跌→`buy_in`;V 形反转→金叉被检测到;数据不足→`hold`
且不抛异常)。

## 明确不做

- 不接 alert_engine / Telegram 推送。
- 不产生任何具体买卖点位、仓位或下单指令。
- 不加 MACD 等更多指标。
